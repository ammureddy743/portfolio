## 🚀 How to Run Locally

### Start Vite Development Server
```powershell
npm.cmd run dev
```
Then visit: `http://localhost:3000` (or the port Vite outputs with instant HMR)

### Production Build
```powershell
npm.cmd run build
```
Compiles TypeScript types and bundles optimized assets into `dist/`.

### Preview Production Build
```powershell
npm.cmd run preview
```
