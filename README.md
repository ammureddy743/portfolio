## 🚀 How to Run & View Locally

### Option 1: Instant View (No Installation Required)
Simply **double-click** `index.html` in Windows Explorer or open it in Google Chrome, Microsoft Edge, or any modern web browser.

### Option 2: Local Web Server
You can launch a local web server using:
```bash
npx serve .
```
or with Python:
```bash
python -m http.server 3000
```
Then visit: `http://localhost:3000`

## 🌐 Free 1-Click Deployment Options

### Deploy on GitHub Pages
1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio release"
   git remote add origin https://github.com/ammureddy743/portfolio.git
   git push -u origin main
   ```
2. In your GitHub repository, navigate to **Settings** > **Pages**.
3. Under **Branch**, select `main` and root `/`, then click **Save**.
4. Your site will be live at `https://ammureddy743.github.io/portfolio/`!

### Deploy on Vercel or Netlify
- Drag and drop this folder directly into [Vercel](https://vercel.com) or [Netlify](https://www.netlify.com) for instant global deployment with custom domain support.
